Built with clear boundaries

Designed to demonstrate reasoning, not pretend to be production.

SYNES is an independent portfolio project using synthetic scenarios and illustrative workflow data. The public preview runs in your browser. A separate local Python incident engine exists but is not connected to this static website. There is no live Tines integration, real AI inference or production reviewer authentication.

Built by a Dublin-based computing graduate with 2.5+ years of BI/ETL operations experience, using SQL, Python and troubleshooting practices.
